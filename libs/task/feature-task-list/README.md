# task/feature-task-list

`@claude-actions/task/feature-task-list` — the routed task board. It provides
`TaskListStore` and composes `@claude-actions/task/ui`; it holds no state and
no subscriptions of its own.

Tagged `type:feature`, the only library type allowed to depend on everything.

## Running unit tests

`npx nx test task-feature-task-list`
